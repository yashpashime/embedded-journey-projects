# Custom String Class

## About the Project

This is my first C++ project. I created a custom `string` class using a dynamically allocated character array instead of using the standard C++ `std::string` class.

The main goal of this project was to understand how C++ classes work internally and to practice Object-Oriented Programming concepts through a practical implementation.

## Concepts Used

* Classes and Objects
* Encapsulation
* Constructors
* Destructor
* Dynamic Memory Allocation
* Character Pointers
* Copying dynamically allocated data
* Operator Overloading
* Assignment Operator
* Comparison Operators
* Concatenation
* Input and Output Operators

## Features

The custom string class implements operations for:

* Creating an empty string
* Creating a string from a C-style string
* Copying strings
* Assigning strings
* Comparing strings
* Concatenating strings
* Reading strings
* Displaying strings

## Compilation

Compile the program using:

g++ ClassString.cpp -o stringclass

Run the program:
./stringclass

## What I Learned

Through this project, I learned how to create and work with classes in C++, manage dynamically allocated memory, and overload operators for user-defined objects.

This project also helped me understand the differences between C-style strings and a custom C++ string class.
